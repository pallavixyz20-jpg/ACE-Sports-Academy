# ACE Sports Academy Website

## Project Description

ACE Sports Academy is a responsive sports academy website developed using
HTML5, CSS3 and JavaScript.

The website provides information about sports training, coaches,
membership plans, events and student registration.

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Local Storage

## Website Features

1. Home Page
2. About Academy
3. Sports Categories
4. Coaches Information
5. Training Programs
6. Membership Plans
7. Training Schedule
8. Student Registration
9. Upcoming Events
10. Sports Gallery
11. BMI Calculator
12. Contact Form
13. Responsive Navigation

## How to Run the Project

1. Install Visual Studio Code.
2. Create a folder named ACE-Sports-Academy.
3. Create the four files listed above.
4. Copy the respective code into each file.
5. Save all files.
6. Install the Live Server extension.
7. Right-click index.html.
8. Select Open with Live Server.

## Registration Functionality

The registration form collects student information and saves it
in the browser using JavaScript Local Storage.

## BMI Calculator

The BMI calculator calculates the Body Mass Index using the
student's height and weight.
